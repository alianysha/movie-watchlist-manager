# Cinebox — Movie Watchlist Manager

A responsive MERN Stack application for organizing movies, tracking viewing progress, and rating watched movies.

## Features

- Add movies with title, genre, release year, runtime, platform, and priority.
- Automatically generate movie codes in the format `MV-<year>-<sequence>`.
- Track movie status: To Watch, Watching, and Watched.
- Require a rating from 1 to 10 when marking a movie as Watched.
- Automatically record the watched date.
- Prevent duplicate movies with the same title and release year.
- Search movies by title and filter by status and genre.
- Paginate movie results with six movies per page.
- Recommend the next movie based on priority and runtime.
- Display dashboard statistics, including total movies, hours watched, average rating, and top watched genre.
- Edit movie details and enforce deletion rules.
- Store movie data in MongoDB Atlas.

## Technology Stack

- **Frontend:** React, Vite, CSS, Axios, Lucide React
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **ODM:** Mongoose

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/movies` | List movies with search, filters, and pagination |
| POST | `/api/movies` | Add a movie |
| GET | `/api/movies/watch-next` | Get the highest-priority movie recommendation |
| GET | `/api/movies/stats` | Get dashboard statistics |
| PUT | `/api/movies/:id` | Edit movie details |
| PATCH | `/api/movies/:id/status` | Change status and manage rating |
| DELETE | `/api/movies/:id` | Delete an eligible movie |

## Setup Instructions

### Prerequisites

Install Node.js and have a MongoDB Atlas database available.

### 1. Configure the Backend

Open a terminal in the project root and run:

```bash
cd backend
npm install
```

Create `backend/.env` with your own test database configuration:

```env
MONGO_URI=your_test_mongodb_atlas_uri
PORT=5000
```

Start the backend:

```bash
npm run dev
```

### 2. Configure the Frontend

Open a second terminal from the project root:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser.

## Validation and Business Rules

- Release year must be between 1950 and the current year.
- Runtime must be between 30 and 300 minutes.
- Movie codes are generated by the backend and cannot be edited.
- Watched movies cannot change status.
- Movies in Watching status cannot be deleted.
- Ratings are allowed only for Watched movies.

## Notes

Use your own valid MongoDB Atlas configuration in `backend/.env`. Never use personal or production credentials in a public repository. For the exam, follow the evaluator's instructions regarding test credentials and environment files.
